# PhotoStudio Android (Flutter)

Direktori ini disiapkan untuk aplikasi Android berbasis Flutter (target Android 10+).
Aplikasi Flutter akan berbagi backend Supabase/PostgreSQL (`../../supabase/migrations`) dan kontrak JSON Template Engine (`../../packages/shared-types`).

## Status Saat Ini
- Flutter SDK belum terdeteksi di lingkungan lokal.
- Setelah Flutter SDK terpasang, jalankan `flutter create . --org com.photostudio.app` di direktori ini untuk menginisialisasi proyek Android.
